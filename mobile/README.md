# Clear - Android app

Flutter client. Signs in, pairs with the desktop, and shows AI answers the
moment they are generated.

## Requirements

- Flutter 3.27 or newer (`flutter --version`)
- Android SDK 34, JDK 17
- A running Clear backend

## First run

```bash
cd mobile
flutter pub get

# emulator (10.0.2.2 is your PC from inside the emulator)
flutter run --dart-define=CLEAR_BACKEND_URL=http://10.0.2.2:8080

# physical phone on the same Wi-Fi
flutter run --dart-define=CLEAR_BACKEND_URL=http://192.168.1.20:8080
```

`android/local.properties` is generated by `flutter pub get`; if you are
building straight through Gradle, create it yourself:

```properties
sdk.dir=C:\\Users\\you\\AppData\\Local\\Android\\sdk
flutter.sdk=C:\\src\\flutter
flutter.versionName=1.0.0
flutter.versionCode=1
```

## Release APK

```bash
node tool/generate_launcher_icons.js        # only needed once
flutter build apk --release --dart-define=CLEAR_BACKEND_URL=https://your-backend
```

Output: `build/app/outputs/flutter-apk/app-release.apk`

### Signing

Debug-signed by default so the build always works. For a real release key:

```bash
keytool -genkey -v -keystore clear-release.jks -keyalg RSA -keysize 2048 \
        -validity 10000 -alias clear
```

Then `android/key.properties`:

```properties
storeFile=../clear-release.jks
storePassword=...
keyAlias=clear
keyPassword=...
```

`android/app/build.gradle` picks it up automatically.

## Structure

```
lib/
├── main.dart              bootstrap: storage, notifications, ProviderScope
├── app.dart               MaterialApp, routes, bottom-nav shell
├── core/
│   ├── config.dart        build-time config + storage keys
│   ├── theme.dart         Material 3 light/dark
│   ├── storage.dart       keystore for tokens, prefs for settings
│   └── notifications.dart answer notifications
├── data/
│   ├── models.dart        Answer, TranscriptLine, Presence, UserSession
│   ├── api_client.dart    REST + transparent token refresh
│   └── socket_service.dart realtime link, heartbeat, latency
├── state/                 Riverpod controllers
└── ui/
    ├── pages/             splash, login, pairing, dashboard, history, settings
    └── widgets/           answer card, status banner, empty state
```
